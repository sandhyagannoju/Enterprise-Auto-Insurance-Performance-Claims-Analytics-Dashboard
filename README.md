# Insurance Analytics Power BI Dashboard

## Project Overview

This Power BI dashboard provides insights into policy sales, premium performance, agent targets and insurance claims.

## Business Questions

- How is premium performance changing over time?
- Which agents and regions perform best?
- Are agents achieving their targets?
- What is the distribution of new and renewed policies?
- Which claim types have the highest claim amount?
- Which regions require management attention?

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Microsoft Excel

## Data Model

The dashboard uses a star-schema model containing:

- Fact_PolicySales
- Fact_Claims
- Dim_Date
- Agent and customer-related dimension tables
